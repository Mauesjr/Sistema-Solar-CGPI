Detailed Description

Classe responsável pela renderização gráfica do sistema solar.

  • Esta classe representa a "Casca Imperativa" (Imperative Shell). Ela não guarda estado físico e não possui regras matemáticas do universo. Apenas lê os dados do núcleo e executa as chamadas do OpenGL para desenhar os pixels na tela.
